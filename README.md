# \# Python Task Manager

# \## Название проекта

# \*\*Python Task Manager\*\* — консольный менеджер задач.

# 

# \## Описание

# Программа предназначена для эффективного управления повседневными задачами в интерфейсе командной строки. Программный продукт решает проблему быстрого создания, отслеживания, выполнения и организации задач без необходимости использования тяжелых графических интерфейсов.

# 

# \## Возможности

# Ниже приведена таблица основных функций программы:

# 

# | Функция | Описание |

# | :--- | :--- |

# | Добавление задачи | Создание новой задачи с указанием текста и сохранение ее в список |

# | Просмотр списка | Вывод всех текущих задач с их статусами |

# | Изменение статуса | Отметка выбранной задачи как выполненной |

# | Удаление задачи | Полное удаление неактуальной задачи из системы |

#

## Использование
Пример стандартного сценария работы:
1. Запустите приложение командой `python src/main.py`.
2. Выберите пункт меню `1` для создания задачи.
3. Введите название задачи (например: `Подготовить отчёт по ЛБ 3-4`).
4. Выберите пункт меню `2`, чтобы убедиться, что задача отображается в списке со статусом `[ ]`.
